The method

A fact is only worth what it is attached to.

We do not hand you a row of numbers and ask you to trust them. Every value is filed under the page it was read from, so you can go and look at it yourself. Where a page gave nothing, the record says that too.

The read

What a read does, in order.

The worked example above is one business. This is the same work every business in the run gets, and the order it happens in.

  1. Open the pages

    The register first, then the business's own site — contact, about, team, in that order. Six pages a site at most. A search result is never a source; a page is.

  2. Read the value, keep the page

    Addresses are taken from mailto and tel links before any pattern matching, because a link is a claim the page made about itself. Whatever is read is filed under the URL it was read from, not under the business.

  3. Test the claim

    The mailbox is checked against its mail server, and the number against a real dialling range. Before either, a made-up address is offered to the server. A server that accepts that one accepts anything, so it is filed as risky — never as verified.

  4. Record what was not there

    A page with no phone number, a year with no filing, a team page naming nobody: each is written down as an empty result with the page that was silent. Silence is a finding, and it is kept.

A run of 148 businesses is that sequence 148 times over. Nothing in it is skipped for being slow, and nothing that came back empty is thrown away.
